# 安心提醒

一个无需安装依赖、可离线使用的中文网页提醒器，适合老年人在手机或电脑上使用。

## 使用方法

1. 用浏览器打开 `index.html`。
2. 首次打开时，按医生处方填写药品名称、剂量和服药时间。
3. 点击“保存设置”后，提醒开始工作。
4. 服药后点击“我已服用，确认记录”，再继续下一种药。

在 Termux 中可以直接运行：

```sh
termux-open index.html
```

## 功能

- 大字、高对比度、触控按钮，减少误操作。
- 药品按时间自动排序，只能依次记录，避免漏记和重复提醒。
- 已服药品锁定并显示记录时间；误点时可撤销。
- 超过计划时间会突出提示，并提醒先核对医生或药师说明。
- 可设置 30、45、60 或 90 分钟久坐提醒、提示音和中文语音。
- 支持浏览器弹窗通知；数据只保存在当前浏览器本地。

## 注意事项

- 本网页只负责提醒和记录，不提供用药建议。
- 浏览器关闭后，普通网页无法继续弹出提醒；需要保持页面打开。
- 部分浏览器会限制本地文件的通知权限。如通知不可用，可保持页面可见，页面内的大字提醒仍会正常工作。
- 换浏览器或清除浏览器数据后，已保存的用药计划和记录会消失。
